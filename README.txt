FINANCE TRACK - actualización de eliminación de registros

Para actualizar GitHub Pages:
1. Descomprimir este ZIP.
2. Subir/reemplazar index.html en la raíz del repositorio finance-track.
3. Esperar a que GitHub Pages termine de publicar.

La aplicación conserva la misma clave de almacenamiento local del prototipo anterior.
Antes de reemplazar archivos, se recomienda descargar una copia JSON desde Más > Descargar copia JSON.
